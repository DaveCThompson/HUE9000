HUE 9000 explores diagetic design, where the user interface is integral to the narrative itself. The goal was to create a digital experience that feels responsive and emotionally engaging.

The interface is inspired by HAL 9000. Unsettling ambient sounds, slow pacing, high-craft visual design combine to create an immersive experience.

This project demonstrates translating brand identity into memorable, interactive design.

Inspiration

HUE 9000 pays homage to Stanley Kubrick's 2001: A Space Odyssey, capturing the film's design principles in a modern interactive experience.

The Living Lens

The central lens uses dynamic gradients and the OKLCH color model to realistically respond to user input, creating an interactive "living" effect reminiscent of HAL's iconic eye.

Atmosphere and Lighting

The interface uses dramatic, high-contrast lighting to guide user attention, echoing the film's visual style.

Physicality of Controls

Digital controls mimic physical buttons through animation, lighting, and realistic sound, enhancing tactile interaction.

Utilitarian Aesthetics

Clean, minimalist design emphasizes functionality and realism.

User Experience Details

  • Tactile Digital Controls
    Rotary dials provide realistic visual and kinetic feedback, bridging digital and physical interaction.
  • Narrative-Driven UI
    Each UI element supports storytelling, from animations to typography, reinforcing the narrative with every interaction.
  • Authentic Materiality
    Custom-rendered textures enhance realism and tactile engagement.
  • Sonic Identity
    Audio design enhances immersion with intentional sounds and interactive feedback.
  • Inclusive & Accessible Design
    Accessibility is fundamental, with semantic structures, comprehensive keyboard navigation, and clear visual cues ensuring an inclusive experience.

Technical Foundation

The technical stack prioritizes performance and interaction quality:

  • Core Technology: Vanilla JavaScript (ES6+)
  • State Management: Custom solution with XState for interactive states
  • Animations: GSAP for fluid animations
  • Audio: Howler.js for robust audio interactions
  • Visual Engine: CSS custom properties and OKLCH color space for consistent visuals.
